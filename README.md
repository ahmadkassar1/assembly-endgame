# Assembly: Endgame
Assembly: Endgame — a React word-guessing game with an 8-life "languages" system.

## Features
- Local random word generator (no external dependency)
- Letter reveal and keyboard interaction
- "Languages" lives system (8 attempts)
- New game reset button
- Componentized React structure

## Install & run (dev)
```bash
npm install
npm run dev
# or
yarn
yarn dev
